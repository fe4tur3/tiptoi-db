# tiptoi-db

Persönliches Haushaltsprojekt zur Verwaltung unserer Tiptoi-Mediensammlung.

## Was?
Tiptoi-Medienmüssen einmalig auf den Stift geladen werden. 
Diese kleine App hilft mir nachzuverfolgen, welche Medien wir besitzen, und ob ich sie noch vorbereiten muss.

## Womit?
- CRUD
- Themen-Kategorisierung
- Ausleih-Status
- Bewertung und Kommentarfeld
- Modales Eingabeformular

## Wer?
- PHP (Backend & DB-Anbindung)
- MariaDB (Datenbankstruktur)
- HTML & CSS (Frontend)
- JavaScript (Modal)

## Wie weit?
Prototyp — läuft lokal. Geplante Erweiterung: 
Suchfeld 

## Ziel
Dieses Projekt entstand parallel zur Umschulung zur Fachinformatikerin AE 
als praktische Anwendung von PHP, SQL und CRUD-Konzepten.

## API / Externe Anbindung
-dynamischen Google-Suchanfragen, statt API
Je nach Kategorie werden automatisch verfeinerte Suchbegriffe 
generiert und als klickbarer Link ausgegeben.
